# Ripper Store Links Revealer

Simple tampermonkey script to reveal links on https://forum.ripper.store for guests and unauthenticated users


# Installation

1. Install the Tampermonkey browser extension: https://www.tampermonkey.net/
   *(I recommend using Firefox, since it also supports browser extensions on mobile.)*
2. Open the following URL in your browser: https://raw.githubusercontent.com/VRCUploader/ripper-store-links-revealer/refs/heads/main/ripper-reveal-links.user.js
   If Tampermonkey is installed correctly, it will automatically detect the userscript and display the installation page.
3. Click **Install**, and you're done!

# Usage

Once installed you can now browse posts on ripper.store and view the links without an account
